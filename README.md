# Student_Performance_Analysis
Student Performance Analysis using Exploratory Data Analysis (EDA)

## 🎯 Objective
Analyze student performance data to understand score distributions, relationships between subjects, and factors affecting academic outcomes.

## 📂 Dataset
The dataset contains academic records of 1,000 students including:
* Gender
* Race/Ethnicity
* Parental Education
* Lunch Type
* Test Preparation
* Math, Reading & Writing Scores

## 🛠️ Tools & Technologies
* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 🔍 EDA Performed
* Dataset and statistical analysis
* Score distribution analysis
* Gender and test preparation comparison
* Correlation analysis between subjects
* Visualizations using histograms, boxplots, and heatmaps

## 📈 Key Insights
* Average math score is approximately 66
* Test preparation is associated with higher math performance.
* Reading and writing scores have a strong positive correlation.
* Performance across math, reading, and writing shows strong relationships.
  ---
  
✅ **Conclusion**
 *This project demonstrates the practical application of Exploratory Data Analysis, statistical analysis, and data visualization to understand student academic performance and discover meaningful patterns in educational data.*
